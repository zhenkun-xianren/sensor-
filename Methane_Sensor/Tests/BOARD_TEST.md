# 甲烷报警装置红外计数显示验收

固件目标：STM32F103C8T6，内部 HSI/2 经 PLL ×16，SYSCLK 64 MHz。烧录 `MDK-ARM/Methane_Sensor/Methane_Sensor.hex`。

1. 上电后确认系统时钟使用 HSI 为 PLL 源，SYSCLK/HCLK 为 64 MHz，APB1 为 32 MHz。
2. 确认数码管扫描软件定时器和 `ir_count` 应用任务正常运行；扫描周期为 5 ms，整屏刷新周期约 20 ms，显示无明显闪烁、缺段或重影。
3. 确认上电显示 `0000`，数码管无小数点。
4. 确认 PA8 红外输入空闲时为高电平；按下遥控器时，在 PA8 观察到低电平脉冲（建议使用示波器或逻辑分析仪）。
5. 对遥控器按下并释放任意按键，确认计数只增加 1；按住按键时，NEC 重复帧不继续增加计数。
6. 确认不同按键（包含非数字键）均能计数，显示前导零正确，例如计数为 1 时显示 `0001`。
7. 红外计数 APP 不启动甲烷传感器、继电器和蜂鸣器业务；确认 PA1 保持高电平（24V_IO_OUT 接近 0 V，为关闭态），PA5、PA6 保持低电平。

主机测试覆盖计数从 0 开始、重复帧忽略、计数饱和于 9999，以及整数显示前导零和越界错误显示。

主机回归测试：在 `Tests/host` 中运行 `powershell -ExecutionPolicy Bypass -File .\run_tests.ps1`。

## RS485 Modbus RTU 周期写寄存器验收

固件使用 USART2：PA2 为 TX，PA3 为 RX，PA4 (`MCU_IO-RS485`) 同时控制 ADM3485 的 DE 与 /RE#。PA4 高电平发送，最后一个停止位发完后拉低进入接收；上电默认低电平。USART3 (PB10/PB11) 仍专用于甲烷传感器。

1. 确认串口为 9600 bit/s、8N1；Modbus RTU 请求地址为 1，功能码为 `0x06`，写保持寄存器 `0x0000`。
2. 用逻辑分析仪确认 PA4 在发送帧期间为高，发送完成后切低；PA2 上每秒出现一帧，寄存器数据从 0 开始递增。
3. 连接从站地址 1，确认 `0x06` 回显应答通过 CRC、地址、功能码、寄存器和值校验；断开从站后确认约 100 ms 超时，下一秒仍继续发送。
4. 主机回归测试覆盖正确回显、错误 CRC、回显字段不匹配、从站异常帧、无应答超时以及每秒自动重载定时器。
