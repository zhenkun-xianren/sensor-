# STM32F103C8T6 共用板级适配

## 内容与适用范围

- `Core/Inc/bsp_board.h`：来源板卡时钟常量。
- `Core/Inc/bsp_gpio.h`、`Core/Src/bsp_gpio.c`：STM32F103C8T6 GPIO 模式、整板引脚定义与初始化。

这是多个模块共用的来源板卡实现。它配置红外输入、甲烷串口、RS485、数码管、执行器和指示灯的引脚，不适用于其他 MCU 或未经核对的电路板。

## 外部依赖与初始化

需要目标工程提供 STM32F1 CMSIS 设备头文件 `stm32f103xb.h`。根据目标工程的时钟初始化顺序启用 AFIO/GPIO 时钟，再按原理图检查安全电平、复用功能、EXTI 映射和引脚冲突。单模块移植时应裁剪或重写整板 GPIO 初始化，避免改动目标工程未使用的引脚。

## 验证状态

来源为 STM32F103C8T6 固件快照；本归档未独立构建或目标板验证。
